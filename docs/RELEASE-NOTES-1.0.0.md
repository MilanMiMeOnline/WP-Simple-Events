# GitHub release notes — 1.0.0

## MiMe Simple Events and Calendar 1.0.0

Version 1.0.0 establishes the stable release line and makes first-event setup
clearer, with smoother calendar startup and easier-to-read recurrence previews.

### Highlights

- Start a new calendar immediately when there are no existing events to index;
  repeated dates no longer wait unnecessarily for a background task.
- Find event dates more easily with guidance explaining Event details and the
  difference between an event date and a page's publication date.
- Review recurrence changes using readable dates and times in your website's
  format, with the event's original local time preserved.
- Load recurrence controls after saving the first event dates, while keeping
  pending recurrence choices when other event details are saved.
- Make list and calendar checks lighter on larger event collections.
- Understand calendar defaults and optional event fields through simpler help
  text.
- Continue using the existing event, calendar, Gutenberg, Elementor and Divi 5
  workflows under the documented 1.x compatibility policy.

### Safety and compatibility

- Existing events, settings, shortcodes, blocks and builder templates retain
  their supported identities and saved values.
- Public event displays continue to exclude unpublished and protected content.
- The plugin adds no visitor tracking, cookies or remote runtime dependencies.
- WordPress 6.9 and PHP 8.2 remain the minimum requirements.

See [CHANGELOG.md](https://github.com/MilanMiMeOnline/WP-Simple-Events/blob/v1.0.0/CHANGELOG.md) for the complete technical changelog.
