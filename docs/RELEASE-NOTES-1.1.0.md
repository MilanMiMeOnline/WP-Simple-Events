# GitHub release notes — 1.1.0

## MiMe Simple Events and Calendar 1.1.0

Version 1.1.0 updates the calendar to FullCalendar 7 while preserving your
existing events, calendar settings and familiar month and list views.

### Highlights

- Use the updated calendar with your existing filters, event colors, date formats
  and links, without rebuilding saved calendars.
- Keep calendars responsive when an Elementor or Divi editor canvas changes size
  or reveals a previously hidden component.
- Retain clear all-day and multi-day labels and the event's local wall time across
  daylight-saving transitions.
- Load the calendar's styles locally, including previews in supported builders.

### Safety and compatibility

- Existing events, recurrence rules, shortcodes, blocks and builder settings stay
  compatible; no event-data migration is required.
- Calendar code and styles remain bundled locally, with no external calendar CDN.
- Public feeds continue to exclude unpublished and protected events.
- WordPress 6.9 and PHP 8.2 remain the minimum requirements.

See [CHANGELOG.md](https://github.com/MilanMiMeOnline/WP-Simple-Events/blob/v1.1.0/CHANGELOG.md) for the complete technical changelog.
