# User guide

MiMe Simple Events and Calendar keeps event publishing close to normal
WordPress publishing. Start with the short route below, then open only the guide
for the task you are working on.

## The shortest route to a working events page

1. [Install the plugin and publish one event](GETTING-STARTED.md).
2. Create a page and insert the **Event List / Grid** or **Event Calendar** block.
3. Use [Displaying events](DISPLAYING-EVENTS.md) to choose filters, colors and
   layout without writing custom CSS.
4. If an event repeats, save its dates first and then follow
   [Recurring events](RECURRING-EVENTS.md).

## Where settings live

- **Events > Add New** creates a normal event.
- **Events > All Events** lists events and summarizes their schedule.
- **Events > Event Categories** manages categories and optional calendar colors.
- **Events > Event Tags** manages event-only tags.
- **Events > Settings** controls the archive, timezone presentation, native Add
  to Calendar, structured data, maintenance and optional data deletion.
- **Settings > General** remains the source for the website timezone, date format
  and time format. The plugin deliberately does not create competing settings.

## Supported environment

- WordPress 6.9 or newer;
- PHP 8.2 or newer;
- Elementor 3.35 or newer when using the optional Elementor integration;
- Divi 5.11.1 or newer when using the optional Divi integration.

Elementor, Divi and WooCommerce are optional. The event editor, native pages,
shortcodes and Gutenberg blocks work without them.
