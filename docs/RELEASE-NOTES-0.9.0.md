# GitHub release notes — 0.9.0

## MiMe Simple Events and Calendar 0.9.0

Version 0.9.0 sharpens performance, accessibility, upgrade safety and everyday
guidance across the complete event-publishing experience before the stable 1.0
release.

### Highlights

- Load recurring-event lists and calendars more efficiently through bounded,
  shared event-data preparation.
- Navigate filters, calendars, pagination and recurrence controls more reliably
  with improved keyboard, focus, enlarged-text and narrow-screen behaviour.
- Upgrade safely from every supported public version with stronger repair,
  deactivation and data-retention qualification.
- Build event pages with the documented Gutenberg, Elementor and Divi 5
  components under a frozen compatibility contract for the future 1.x line.
- Follow a new task-based guide covering first events, recurrence edit scopes,
  filters and colors, builders, privacy, ownership and troubleshooting.
- Keep repeated event collections accessible and mobile calendar list views
  contained within their page layout.

### Safety and compatibility

- Existing events, recurring series, pages, settings and saved builder layouts
  remain compatible; this release does not require content migration by users.
- The plugin adds no telemetry, visitor cookies, remote runtime assets or public
  write endpoint, and event exports continue to fail closed for protected or
  ineligible content.
- Qualified on WordPress 6.9 and 7.1 with PHP 8.2 through 8.5.
- The official WordPress Plugin Check completed with no errors.

See [CHANGELOG.md](https://github.com/MilanMiMeOnline/WP-Simple-Events/blob/v0.9.0/CHANGELOG.md) for the complete technical changelog.
